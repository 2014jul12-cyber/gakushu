れんしゅう メニュー (アプリとして入れる方法)

【GitHub Pages に置く場合】
1. github.com で無料アカウントを作り、新しいリポジトリを作る (Public)。
2. 「Add file」→「Upload files」で、このフォルダの中身を ぜんぶ ドラッグして Commit。
   ※ zip のまま ではなく、解凍して 中のファイルを 上げます。
3. Settings → Pages → Branch を main / (root) にして Save。
4. 数分後に https://(ユーザー名).github.io/(リポジトリ名)/ が 開けます。
5. タブレットの Chrome で そのURLを開き、メニュー(︙)の「ホーム画面に追加」または「アプリをインストール」を押す。
6. 一度 開いたあとは、ネットなしでも 動きます。
